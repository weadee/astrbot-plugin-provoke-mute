# 挑衅禁言（astrbot_plugin_provoke_mute）

群友出言挑衅？机器人自动送上一份禁言套餐，并附一句回怼。

只支持 **aiocqhttp**（OneBot v11，NapCat / Lagrange / go-cqhttp 等），因为要用 `set_group_ban` 这个群管接口。

> **⚠️ 新版默认是「观察模式」**：命中只发提示、**不真禁言**。
> 先跑一两天，用 `挑衅禁言 记录` 看有没有误伤，确认准了再执行 **`挑衅禁言 观察 关`** 转真实禁言。

## 它能做什么

- **自动检测挑衅**：内置词库（辱骂、挑事句式、"滚/闭嘴"这类命令口吻，以及"来禁言我/有本事禁言我/封我啊"这类**主动叫板**），命中就禁言发送者
- **重复刷屏检测**：同一个人短时间内**连发两条相同消息**就吃禁言 —— 与内容无关，刷屏本身就是违规。标点、空格、大小写差异会被忽略；可选相似度阈值（默认要求完全相同）
  - 内置豁免：`哈哈` `666` `收到` `好的` `ok` 这类没信息量的短句连发**不算**刷屏
  - 觉得还是误伤，就 `挑衅禁言 刷屏 挑衅` 切成「只有挑衅话重复才算」
- **两种判定模式**
  - `bot`（默认）：只有冲着机器人来的挑衅才算 —— 带 At 机器人、引用机器人消息，或消息里出现"机器人/bot/小布"等称呼（"来禁言我"这类叫板也算冲着机器人来的）
  - `any`：全群扫描，谁的挑衅都管（误伤率高，建议配好白名单再用）
- **累犯阶梯升级**：30 分钟内重复挑衅，禁言时长按倍数递增，有上限
- **冷却保护**：同一人 10 秒内的后续消息不再重复触发
- **戳一戳连击**：60 秒内戳机器人 3 次，同样吃禁言
- **豁免机制**：群主/群管理员默认豁免（可关），另可单独豁免某个人或某个群
- **观察模式**：命中只提示不真禁言，用来调词库和验证误伤率（**默认开启**）
- **完整管理指令**：开关、改时长、改模式、改刷屏阈值、增删词条、手动禁言/解禁、查看记录

## 安装

**方式一（推荐）**：仓库页面点 `Code` → `Download ZIP`，解压出 `astrbot_plugin_provoke_mute` 整个目录，丢进 AstrBot 的 `data/plugins/`，在 WebUI 插件页重载即可。

**方式二**：`git clone` 本仓库到 `data/plugins/astrbot_plugin_provoke_mute/`。

依赖：无第三方库，仅使用 AstrBot 内置能力。

**前置条件**：机器人必须是目标群的**管理员**，否则会返回"权限不足"。目标也不能是群主或同级管理员。

## 指令

| 指令 | 说明 |
| --- | --- |
| `挑衅禁言` | 输出指令树（框架自动生成） |
| `挑衅禁言 帮助` | 指令一览 |
| `挑衅禁言 状态` | 当前开关、模式、时长、词条数、统计 |
| `挑衅禁言 开` / `挑衅禁言 关` | 启用 / 停用自动禁言 |
| `挑衅禁言 时长 300` | 设置基础禁言秒数 |
| `挑衅禁言 模式 机器人` / `挑衅禁言 模式 全群` | 切换判定模式（立即生效并保存） |
| `挑衅禁言 刷屏 2` | 设置重复刷屏阈值（连发几遍相同消息触发，已保存） |
| `挑衅禁言 刷屏 挑衅` / `挑衅禁言 刷屏 全量` | 检测范围：只管挑衅话重复 / 任何内容重复 |
| `挑衅禁言 刷屏 关` / `挑衅禁言 刷屏 开` | 关闭 / 恢复默认刷屏检测 |
| `挑衅禁言 观察 开` / `挑衅禁言 观察 关` | 观察模式：命中只提示不真禁言 / 恢复真实禁言 |
| `挑衅禁言 词列表` | 查看词库 |
| `挑衅禁言 词添加 你是猪吗` | 添加关键词 |
| `挑衅禁言 词添加 re:你(?:是|真)菜` | 添加正则词条 |
| `挑衅禁言 词删除 2` / `挑衅禁言 词删除 你是猪吗` | 按序号或内容删除 |
| `挑衅禁言 词重置` | 清空自定义词库（内置词库不动） |
| `挑衅禁言 豁免列表` | 查看豁免名单 |
| `挑衅禁言 豁免添加 @某人` / `挑衅禁言 豁免添加 10001` | 加入豁免 |
| `挑衅禁言 豁免删除 @某人` | 移出豁免 |
| `挑衅禁言 忽略本群` / `挑衅禁言 监控本群` | 当前群豁免 / 恢复检测 |
| `挑衅禁言 禁言 @某人 600` | 手动禁言，秒数可省略 |
| `挑衅禁言 解禁 @某人` | 解除禁言 |
| `挑衅禁言 记录 20` | 查看最近记录（默认 10 条） |
| `挑衅禁言 测试 你这个废物机器人` | 试一句，看会不会命中 |
| `挑衅禁言 清空记录` | 清空记录与累计次数 |

指令默认 **AstrBot 全局管理员**或**群主/群管理员**可用，可在配置里收紧。

别名：`provoke`（例如 `provoke 状态`）。

> 注意指令要带空格：`挑衅禁言 状态`，不是 `挑衅禁言状态`。

## 配置

WebUI 插件配置页里可以改（对应 `_conf_schema.json`）。几个关键的：

- `dry_run`：观察模式，**默认开**，确认没误伤后用指令关掉
- `target_mode`：`bot` / `any`，见上
- `ban_duration`：基础时长，默认 180 秒
- `casual_patterns`：玩笑/抬杠句式（"你行你上""不服来 solo""你个二百五"），**默认关**，开了误伤率会明显上升
- `detect_repeat` + `repeat_limit` + `repeat_window_seconds`：重复刷屏检测，默认 20 秒内连发 2 遍相同消息就禁言
- `repeat_scope`：`all` = 任何内容重复都算（默认）/ `provocation` = 只有挑衅话重复才算
- `repeat_ignore_words`：刷屏豁免短句，内置一批，这里填额外的
- `repeat_min_length`：纳入检测的最短长度，默认 2（避免"嗯""？"被误判）
- `repeat_similarity`：1.0 = 必须完全相同；调低则近似消息也算重复
- `escalate` + `escalate_step` + `max_duration`：升级规则，默认每次 +50%，上限 1 小时
- `cooldown_seconds`：冷却，默认 10 秒
- `detect_poke` + `poke_limit`：戳一戳连击，默认 60 秒内 3 次
- `exempt_group_staff`：群主/群管豁免，**默认开，别关**
- `reply_templates`：回怼文案，可用 `{user}` `{duration}` `{count}` `{reason}`
- `stop_after_mute`：禁言后是否中断事件（默认中断，不再走大模型）

词条写法：普通文本按"包含"匹配；以 `re:` 开头按正则匹配（忽略大小写）。正则写错了会被跳过并在日志里警告，不会让插件崩掉。

## 数据存储

词库、豁免名单、开关与时长、判定模式、刷屏阈值、违规计数、最近 100 条记录都写在插件 KV 存储里，重启不丢。命令 `挑衅禁言 清空记录` 只清记录和累计次数。

## 误伤了怎么办

按这个顺序排查，一条一条收紧：

1. **先开观察模式**：`挑衅禁言 观察 开` —— 之后命中只发提示，不再真禁言
2. **看记录找元凶**：`挑衅禁言 记录 20`，每条都写了判定原因
   - 写「连发 N 遍相同消息」→ 刷屏检测，看第 3 条
   - 写「命中挑衅词」→ 词库，看第 4 条
3. **刷屏误伤**（正常话连发被判违规）：`挑衅禁言 刷屏 挑衅` 切成「只管挑衅话重复」；
   个别句子还要豁免就填进 `repeat_ignore_words`
4. **词库误伤**（某句话不该算挑衅）：`挑衅禁言 测试 <那句话>` 确认是哪条命中，
   然后关掉 `casual_patterns`，或者从 `any` 切回 `bot` 模式
5. **已经误禁了好人**：`挑衅禁言 解禁 @某人` 放人，`挑衅禁言 豁免添加 @某人` 以后不再管他

最省事的组合：`bot` 模式 + 观察模式 + `挑衅禁言 刷屏 挑衅`。

## 已知边界

- 只支持 aiocqhttp，其他平台会直接不处理
- 机器人必须自己就是群管理员
- 群成员身份（群主/群管）取自 OneBot 事件里的 `sender.role`，部分协议端可能不返回该字段，此时会退化为不豁免
- 重复刷屏的计数存在内存里，重启 AstrBot 会清零（违规次数和记录是持久化的）
